# 갤럭시 + Office 365 계정(bhlee@emct.ai) 설정 가이드

작성일: 2026-10-14
대상: 삼성 갤럭시 폰에서 Office 365 계정의 캘린더·메일을 삼성 앱으로 사용하는 경우

---

## 1. 증상

- 삼성 캘린더에 같은 캘린더가 중복으로 생김
  - "Calendar" 약 20개, "EMCT.KR.Sales" 약 5개
- 원인: 같은 계정의 동기화가 꼬여서 캘린더가 반복 생성된 것으로 추정
  (계정을 여러 번 추가/삭제했거나 Exchange 동기화 오류가 났을 때 발생)

---

## 2. 중복 캘린더 정리

1. 설정 → 계정 및 백업 → 계정 관리 → `bhlee@emct.ai` 계정 삭제
   - Outlook 앱으로만 연결한 경우 Outlook 앱 설정 → 해당 계정 → 계정 삭제
2. 설정 → 애플리케이션 → 필터/정렬 → **시스템 앱 표시** 켜기
3. **캘린더 저장소** → 저장공간 → **데이터 삭제**
4. 폰 재부팅
5. 계정 재추가 (아래 3, 4장 참조)

> 주의: 계정을 삭제해도 서버(Office 365)의 일정과 메일은 삭제되지 않음.
> 단, 폰에만 저장된 로컬 일정은 3번 단계에서 지워질 수 있음.

---

## 3. 캘린더 설정 (성공한 방법)

> 삼성 기본 메뉴의 **Exchange ActiveSync 직접 입력** 방식은 인증 오류가 발생하므로 사용하지 않음.
> (Microsoft가 구형 기본 인증을 차단한 영향)

1. 플레이스토어에서 **Microsoft Outlook** 앱 설치
2. Outlook 앱에서 `bhlee@emct.ai` 로그인 (비밀번호 + 2단계 인증)
3. Outlook 앱 → 왼쪽 위 프로필/홈 아이콘 → 설정(톱니바퀴) → 해당 계정
   → **캘린더 동기화(Sync calendars)** 켜기
4. 캘린더 접근 권한 팝업이 뜨면 **허용**
5. 삼성 캘린더 앱에서 별도 계정 추가 없이 자동 표시됨
   - 안 보이면 메뉴(≡) → 캘린더 관리에서 `bhlee@emct.ai` 아래 캘린더 체크
   - 삼성 캘린더 앱 안에서 계정을 추가하려 하면 오류가 나므로 하지 않음

### 정상 동기화 시 표시되는 캘린더

Calendar, Emct전체, EmctUSA, EmctVN, EMCT.KR.Sales, Emct경영지원팀, Emct필드엔지니어링팀, 한국의 공휴일 (각 1개씩)

---

## 4. 메일 설정 (삼성 이메일 앱)

> Outlook 앱에 추가한 계정은 삼성 이메일 앱에 반영되지 않음. 삼성 이메일에서 별도로 추가해야 함.

1. 삼성 이메일 앱 → 설정 → 계정 추가
2. 계정 유형을 **Outlook (Office 365)** 으로 선택 (웹 로그인 창이 뜨는 방식)
3. `bhlee@emct.ai`로 로그인 (비밀번호 + 2단계 인증)

---

## 5. 계정 추가가 안 될 때

| 증상 | 조치 |
|---|---|
| "계정을 확인할 수 없음" | Samsung Email 앱을 Galaxy Store/플레이스토어에서 최신 버전으로 업데이트 |
| 로그인 중 404 화면 | 설정 → 애플리케이션 → Samsung Email → 기본값으로 설정 → **지원되는 링크 열기** 켜기 |
| 위 조치로도 404 | 404 화면에서 우상단 메뉴 → "삼성 인터넷에서 열기" → 주소창 옆 Samsung Email 아이콘 눌러 완료 |
| 계속 실패 | Samsung Email 앱 데이터/캐시 삭제 후 재시도 (앱에 등록된 계정은 초기화됨) |
| Outlook 앱은 되는데 삼성 앱만 안 됨 | 회사 관리자에게 Entra(Azure AD) 로그인 기록, 앱 동의 및 조건부 액세스 정책 확인 요청 |

---

## 6. 주의사항

- 삼성 이메일과 Outlook 앱 **양쪽에서 캘린더 동기화를 켜면** 캘린더가 다시 중복될 수 있음
  - 중복이 보이면 한쪽의 캘린더 동기화를 끌 것
  - 삼성 이메일: 설정 → 계정 → 해당 계정 → 동기화 항목
- 메일은 삼성 이메일 앱과 Outlook 앱 모두에서 사용 가능하며 서로 독립적으로 동작함
